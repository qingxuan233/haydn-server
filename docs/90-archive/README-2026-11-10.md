把一台闲置的 **Redmi K40 Pro（M2012K11C / 内部代号 `haydn` / 骁龙 888 / SM8350）** 改造成一台低功耗、可远程维护的家用 Linux 服务器。

- 目标：SSH 远程登录、文件同步/备份、轻量 Web 与自托管服务、下载/定时任务
- 原则：**先零风险上线（Termux + proot），再用运行数据决定是否解锁 Root 升级**
- 状态（2026-11-10）：**P0 完成**；2026-11-10 发生过一次「误删系统必需包导致 bootloop」，已恢复出厂并**从备份重建服务器**（复盘见 [08 事故复盘](../20-server/08-事故复盘与重置重建报告.md)）；当时 **12/12 服务 RUNNING**（CI Runner 常驻，卡片按治理移除），**控制台 v2 已上线**（实时指标/趋势/服务健康/日志/备份，见 [13 控制台功能分析](../40-console/13-控制台功能分析与完善.md)）、**重启自动拉起（当时实测 43s 就绪）**、公网入口恢复
- 动态 IP / 入口切换：控制台自动检测当前局域网 IP；公网页面可一键跳到局域网，也支持 `?to=lan`（公网→局域网）与 `?to=public`（局域网→公网 HTTPS）自动跳转；WiFi IP 变化后仍可用固定公网入口（管理/只读两套），详见 [13 控制台功能分析](../40-console/13-控制台功能分析与完善.md) §4.1/§4.3
- 账号密码：**加密保险库**已上线（AES-256-CBC + HMAC，管理 token 解锁后可增删改查/搜索/复制/导入导出），并已导入服务器现有 **9 条**凭据（WebDAV/Gitea/Syncthing/Supervisor/DSH/备份口令/控制台 token/Runner token/SSH），详见 [15 账号密码保险库](../40-console/15-账号密码保险库.md)

## 核心结论（一句话版）

| 问题 | 结论 |
|---|---|
| 能刷原生 Linux（postmarketOS/Ubuntu Touch 等）吗？ | ❌ 不可行——haydn 没有任何可刷的移植 |
| 不解锁能用 Linux 吗？ | ✅ 可以：Termux + proot-distro（假 root、无 systemd、无容器、I/O 有损耗） |
| 能跑 Docker 吗？ | ❌ **实测否决**：内核 `CONFIG_USER_NS`、`CONFIG_PID_NS` 未启用，容器无法创建命名空间 |
| 能解锁 Root 吗？ | ❌ **不行（已确认）**：国行为 CN 区域，小米社区 App 无解锁入口（2026 年国行官方解锁关闭）→ 走 **A+ 无 Root 优化**（[06 A+ 优化方案](../20-server/06-A+优化方案.md)） |
| 解锁后 KernelSU 还是 Magisk？ | **Magisk 优先**（5.4 QGKI 非 GKI 2.0；KernelSU 需自编译内核） |
| 长期插电电池怎么办？ | 系统"充电保护" / Root 后 ACC 限充 60–80% + 通风散热 |

> **深度清理结果（2026-11-10）**：活跃包 **390 → 252 → 248**（二轮清理后）、禁用 10；MemAvailable **2.21 → 约 4.1 GiB**、/data 释放约 6GB；12 个服务器服务与 SSH 全程正常。详见 [06 A+ 优化方案](../20-server/06-A+优化方案.md)。

> **DSH 已重新部署于手机服务器（2026-11-10）**：Node 24 + @deepseek-ai/dsh 0.2.2-rc.1，127.0.0.1:3081，supervisord 托管；复用原 `https://<手机IP>:8443/app/` 入口（公网入口，Basic Auth），详见 [07 DSH 与 Linux 优化](../30-dsh/07-DSH与Linux优化.md)。

## 重要警告（归档时）

- **解锁 Bootloader 会清空全部数据且不可恢复**，并通常失去保修；
- **归档时未 Root、未解锁**，任何 "刷机/容器/系统级调优" 文档里的操作都**不要直接照抄**，按 [00 项目规划](../00-overview/00-项目规划.md) 的阶段与 [04 风险与回滚](../10-device/04-风险与回滚.md) 的准入检查表执行；
- `inventory/` 内含设备序列号、网络地址与应用清单，**不要公开上传**；
- 公网入口经 frp 受控开放；局域网可独立使用；ADB 不长期开启。

## 安全与隐私

- 手机端 SSH 只启用公钥认证；
- 不把 ADB 无线调试长期开着；用完关闭；
- 关键配置与服务清单纳入 Git（不含密钥；密钥单独保管）。
