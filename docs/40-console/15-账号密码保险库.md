## 1. 安全设计

| 项目 | 方案 |
|---|---|
| 加密算法 | **AES-256-CBC + HMAC-SHA256（encrypt-then-MAC）**，每次写入随机 16 字节 IV |
| 密钥 | `/root/server/etc/vault.key`（32 字节，权限 600），独立于管理员 token |
| 数据 | `/root/server/etc/vault.enc`（密文 JSON，权限 600），原子写入（临时文件 + rename） |
| 完整性 | HMAC 先校验再解密，密文被篡改会拒绝 |
| 访问控制 | **管理 token**（`console-action.token`）+ **HTTPS 或局域网** 双重门禁 |
| 公网 HTTP | `403`，不返回任何账号数据 |
| 日志 | 不记录密码/内容；仅在 `vault-actions.jsonl` 记录操作类型、条目 id/标题、时间、来源 IP |
| 浏览器 | 管理 token 仅存 `sessionStorage`；密码只在已解锁页面内存中出现；列表密码默认掩码 |
| 备份 | `server-backup` 包含 `etc/`，保险库密文和密钥随备份一起加密保存 |

> ⚠️ **密钥丢失 = 密文不可恢复**。请用页面的「导出」保存一份明文备份到可信位置，或确保服务器备份与密钥安全。

### 1.1 管理入口与审计（速查）

| 项 | 入口/位置 | 说明 |
|---|---|---|
| 页面入口 | Console 详情视图 `?view=details` →「账号密码」区域（[34](34-Console总览详情改版.md)） | 需先「解锁管理」（管理 token） |
| API 入口 | `/api/vault*`（见 §3） | 需 `X-Console-Token` + HTTPS 或局域网 |
| 解锁口令 | `/root/server/etc/console-action.token`（600） | 用 SSH 读取；轮换后所有已解锁浏览器需重新输入 |
| 审计日志 | `/root/server/logs/vault-actions.jsonl` | 只记操作类型、条目 id/标题、时间、来源 IP；**不含密码/内容** |
| 数据/密钥 | `vault.enc` / `vault.key`（均 600） | 随 `server-backup` 加密备份 |

> 审计要点：① 口令只以密文落盘，文档/仓库/聊天不写值；② 导出为明文，用完即删；③ 密钥与备份口令分开保管；④ 管理 token 泄露等同保险库泄露，需立即轮换。

## 2. 使用方式

1. 打开控制台（LAN `http://<当前IP>:8080/` 或公网 HTTPS 入口（见运维私密记录））；保险库在**详情视图** `?view=details` 的「账号密码」区域（或从总览「快捷入口」进入，IA 见 [34](34-Console总览详情改版.md)）；
2. 右上角「解锁管理」，输入 token：
   ```bash
   ssh -p 2222 root@<手机IP> 'cat /root/server/etc/console-action.token'
   ```
3. 页面「账号密码」区域：
   - **＋ 新增**：名称（必填）、用户名、密码、网址、标签、备注；
   - **查看**：密码默认 `••••••`，可显示/复制；用户名/网址/标签/备注均可复制；
   - **编辑 / 删除**：二次确认；
   - **搜索**：按名称、用户名、网址、标签、备注过滤；
   - **导出**：下载 JSON（含明文密码，需确认）；
   - **导入**：选择导出的 JSON（同 id 合并/更新；也可用数组格式）。

## 3. API

所有 `/api/vault*` 均要求 `X-Console-Token`，且仅 HTTPS 或局域网。

| 方法/路径 | 说明 |
|---|---|
| `GET /api/vault` | 返回 `{count, items[]}`（含密码；仅管理员） |
| `GET /api/vault/export` | 导出全量 JSON（明文） |
| `POST /api/vault` | 新增/更新：`{id?, title, username, password, url, tags, notes}` |
| `POST /api/vault/delete` | 删除：`{id}` |
| `POST /api/vault/import` | 合并导入：`{entries:[...]}` |

## 6. 已知限制

- 单管理员模型（沿用管理 token）；不支持多用户/角色、TOTP；
- 管理 token 泄露等于保险库泄露，请妥善保管并定期轮换；
- 自签证书的公网 HTTPS 需要浏览器“继续”；
- 导出文件是明文，请勿放在公开共享目录；
- 浏览器复制密码依赖系统剪贴板，公共电脑使用后请清空。

```bash
mv /root/server/etc/vault.enc /root/server/etc/vault.enc.old
# 保留 vault.key 则新库继续使用同一密钥；删除它则换新密钥（旧库无法再解密）
```
