# 09 · 文件管理增强：文件夹打包下载

> 日期：2026-11-10 14:50–15:05
> 目标：让 `http://192.168.10.143:8080/files/`（以及公网 `47.97.70.99:48108/files/`）支持**下载整个文件夹**（zip 打包）。

---

## 1. 使用方式

### 1.1 列表页

打开 `/files/` 登录后：

| 操作 | 入口 |
|---|---|
| 下载某个文件夹 | 文件夹行右侧新增 **⬇** 按钮（悬停提示"下载文件夹（zip）"） |
| 下载当前所在文件夹 | 工具栏新增 **🗜** 按钮（"打包下载当前文件夹"） |

- 下载的是 **zip 文件**，文件名 = 文件夹名 + `.zip`（根目录为 `网盘.zip` / `项目.zip`）。
- 支持嵌套目录；zip 内保留相对路径（如 `nested/deep/c.bin`）。
- 已登录用户（Web 登录 cookie / Basic Auth）才可下载；未登录返回 401。

### 1.2 直接调用（API）

```bash
# 需要网页登录态（cookie）或 Basic Auth（用户名 admin，密码见 /root/server/webdav.yaml）
curl -u admin:<password> \
  'http://192.168.10.143:8080/files/api/zip?root=webdav&path=文件夹名' \
  -o 文件夹名.zip

# root 可选值：webdav（可读写网盘 /root/webdav） / server（只读项目 /root/server）
```

---

## 2. 实现细节（`/root/server/webui/app.py`）

- 新增路由：`GET /files/api/zip?root=<webdav|server>&path=<相对路径>`
- 后端流程：
  1. 复用原有 `_resolve()`：做 `..`/越界校验，只允许 `ROOTS` 内的路径；
  2. 校验必须为目录；
  3. `os.walk(followlinks=False)` 遍历（**跳过符号链接**，避免把 root 外的文件打进包）；
  4. 先统计总大小，临时空间不足 10% 时返回 **507**（防撑爆 `/tmp`）；
  5. 写入 `/tmp/files-zip-*.zip`（Zip64 支持）；音视频/图片/超大文件用 **ZIP_STORED**，其余用 deflate；
  6. 以 `Content-Type: application/zip` + `Content-Disposition: attachment` 发送，发送后删除临时文件；
  7. 兼容断连（`BrokenPipe`/`ConnectionReset` 静默处理）。
- 前端（`static/index.html`）：
  - `rowsHTML()` 对 `e.is_dir` 增加 `⬇` 链接（带会话 token，点击阻止冒泡避免误触打开）；
  - 工具栏新增 `#btn-zip`，点击跳转当前文件夹的 zip 地址。

## 3. 安全边界

| 项 | 策略 |
|---|---|
| 路径穿越 | 沿用 `_resolve()`，禁止 `..`、绝对路径、越界 root |
| 符号链接 | 打包时跳过，防止读到 root 外文件 |
| 权限 | 未登录 401；`server` 只读根仅允许下载（不允许写） |
| 资源 | 临时空间 90% 上限检查；流式读取 256KB 分块；发送后清理临时文件 |
| 文件名 | `_safe_zip_name()` 去除路径分隔/控制字符并限长，Content-Disposition 使用 RFC5987 编码 |
