## 4. 下一步（按优先级）

### P1 · 24h soak（Phase 4 前置，最优先）
- 连续 24h 观察：Bridge `/v1/health`、`/api/sysinfo` 的 `bridge_source`/`age`、服务器 12/12、DSH `/app-login`；
- 期间**不改** Bridge/服务器核心配置；记录可用率、失败次数、回退次数（目标 ≥99%）；
- 产出：soak 记录（追加到 [33 Bridge MVP 实施记录](../50-bridge/33-Android-Bridge-MVP实施记录.md) 或独立记录后再归档）。

### P2 · Phase 2 剩余（加固）
- `usage` 权限自恢复：重启后 `GET_USAGE_STATS` 回 default，需要 App 引导 Settings 或维护脚本（ADB）再授权；
- mTLS / 配对码 + 一次性 token exchange / 证书轮换 / Android Keystore 硬件-backed key；
- OEM profile 白名单脚本与指引（MIUI 人工已验证，其他 OEM 按 [32 多厂商适配](../10-device/32-多厂商Android适配与迁移指南.md) 矩阵）；
- release 重装/token 配对 runbook 文档化（同签名 key 原地 `install -r`、token 保留已验证）。

### P3 · Phase 4 全栈验收
- 5 次重启、24h soak、Bridge 杀进程/断网/401/超时、Server 重启、DSH 重启、APK 升级/回滚；
- 验收清单 A1–A8 见 [28 §11.6](28-全栈整体方案规范.md)。

### P4 · 可选（需用户先确认）
- 外部服务接入（Uptime Kuma / 异地备份 / MFA / Tailscale）——**未获确认不做**；
- Phase 3 Shizuku 特权字段——默认不做；
- 换机/OEM 迁移——按 [32 多厂商适配](../10-device/32-多厂商Android适配与迁移指南.md)。

## 6. 护栏（必须遵守）

1. **不 Root、不刷机、不解锁 BL**；不装系统/priv-app；B 路线已取消（Gate B0 失败）。
2. **不卸载系统包**；不执行 `am kill-all`；不改 Android 系统设置（ADB 维护性优化除外，且需记录）。
3. **不把 Bridge token/证书/DSH token/备份口令/公网入口具体值**写入日志、聊天、公网页面。
4. **DSH 不直连 Bridge、不持 token、不试图启动 App**；只走 Server API / `server-ops`。
5. **写操作走 server-ops Tier2**（`--confirm` + 快照 + 审计）；Tier3 只人工 SSH。
6. **外部服务**（Uptime Kuma/异地备份/MFA/Tailscale）未获确认不做；不新增公网端口。
7. **不重装服务器**除非按 [17 构建手册](../20-server/17-研究平台环境构建手册.md)；重装前先备份并确认回滚。
8. **构建路径必须 ASCII**（`aapt2` 不支持中文路径）；不要恢复旧的 ASCII junction 方案。

## 8. 常用只读命令

```bash
# 服务/健康（服务器侧）
server-ops status
server-ops health
server-ops bridge status
server-ops logs dsh --lines 100

# 当前状态 API
curl -s http://127.0.0.1:8080/api/sysinfo
curl -s "http://127.0.0.1:8080/api/ops?n=5"

# Bridge（loopback + token；token 不要写入聊天/日志）
curl -sk https://127.0.0.1:3099/v1/health
curl -sk -H "Authorization: Bearer <token>" https://127.0.0.1:3099/v1/status
```

```powershell
# PC 侧：构建 APK（产物 build/bridge.apk + build/bridge.crt）
powershell -NoProfile -ExecutionPolicy Bypass -File android-bridge\build.ps1

# PC 侧：文档链接检查（自己改动范围内 error 必须为 0）
& 'C:\Users\69559\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe' scripts\dev\check-links.py
```

> 只读优先：先 `status`/`health`/`sysinfo` 判断现状，再做任何 Tier2 写操作。

## 9. 新会话启动建议

把下面这句话发给新会话：

1. `server-ops status` / `server-ops health` / `/api/sysinfo` 是否正常（12/12、`bridge_source=bridge`）；

4. 自己的改动是否只落在被授权文件（见 [29 §9 维护规则](29-项目文档评审报告.md)）。
