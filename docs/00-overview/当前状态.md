## 7. 已知限制（无 Root 的硬边界）

1. **无 Root**：全局 `/proc/stat` 精确 CPU、`/proc/net/dev` 原始字节、`dumpsys` / `settings` / 冻结 / 停用等系统级能力不可得；Bridge 只提供"App 可访问状态"，不可得字段一律 `null`。
2. **MIUI/HyperOS 权限重置**：重启后 `POST_NOTIFICATIONS` 被重置为 ignore（FGS 仍工作）；`GET_USAGE_STATS` 回到 default（usage 字段为空，需再授权或引导设置）。
3. **MIUI 自启动需人工一次**：Bridge 需在"自启动管理"中允许；仅 appops/deviceidle 不足以绕过后台启动拦截。
4. **DSH 不能启动 Android App**：不要让 DSH 控制 Bridge 生命周期；Bridge 失败只回退 Termux 采集。
5. **容器不可用**：内核未启用 USER_NS/PID_NS，Docker/Podman 不可用（已否决）。
