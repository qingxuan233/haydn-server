## 8. 2026-11-11 结构与命名重构评审

### 8.1 背景与原因

| 问题 | 事实 | 影响 |
|---|---|---|
| 仓库目录名含中文 | 重构前仓库目录名为中文（原"手机优化"） | Windows 上 `aapt2` 不能处理含中文的路径，构建报 `Failed to stat ... android.jar`/assets 路径错误 |
| 历史绕过方案 | 构建脚本创建 ASCII junction：`D:\android-sdk` → `tools/android-sdk`、`D:\bridge-src` → `android-bridge` | junction 易丢失/需重建成/隐藏外部依赖；换机、清理后构建不可复现 |
| 文档平铺重号 | `docs/` 平铺 + `NN-` 前缀，09/10/11/13/17 重号；裸 `docs/NN` 引用 | 新会话/工具难以定位，机械迁移后出现坏范围引用（如"21–28"被替换成路径片段） |
| 变更记录膨胀 | 历史变更全部追加在 00 项目规划头部（两套 v1.6–v1.16 重号） | 文档头部陈旧、无法审计 |

### 8.4 构建脚本去 junction（2026-11-11）

- `android-bridge/build.ps1` 不再创建 `D:\bridge-src` / `D:\android-sdk` junction（旧的已删除）；
- 自动探测：SDK `$env:ANDROID_HOME` → `$env:ANDROID_SDK_ROOT` → 仓库 `tools/android-sdk`；JDK `$env:JAVA_HOME` → 常见安装目录 → PATH 中的 `javac`；
- **强制 ASCII 路径**：检测到非 ASCII 路径直接报错并提示改名（原中文目录是 aapt2 失败根因）；
- 构建链不变：aapt2 + javac + d8 + zipalign + apksigner（**无 Gradle**）；产物 `android-bridge/build/bridge.apk` + `build/bridge.crt`（gitignored）；
- 验证：Phase 0 门禁 G0 重新通过，产物为 release 签名 APK。
