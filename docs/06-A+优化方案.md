# 06 · A+ 优化方案（无 Root，落地版）

> 背景：**Gate B0 判定失败**——用户确认小米社区 App 无解锁入口，结合 2026 年"国行机型官方解锁关闭"的政策情报，**B 路线（解锁 + Root + chroot）终止**。
> 按 [00-项目规划](00-项目规划.md) 的兜底分支，转为 **A+：不 Root 的深度优化**。
> 本文档记录：现状盘点、已执行优化（T2）、待执行清单、验收指标与回滚方式。
> 执行记录（含原值/回滚命令）：`inventory/apply-a-plus-latest.md` 与 `inventory/apply-a-plus-*.json`。

---

## 1. 决策与事实

| 项目 | 结论 | 依据 |
|---|---|---|
| Gate B0（解锁可行性） | ❌ **失败** | 小米社区 App（`com.xiaomi.vipaccount`）**无解锁入口**（用户 2026-11-10 确认）；设备为 CN 国行（`ro.miui.region=CN`） |
| B 路线（解锁 + Root + chroot） | **终止**，不再尝试 | 官方解锁通道不可用；第三方付费/漏洞解锁不采用（风险与诈骗高发） |
| 破坏性操作 | **未执行任何**：未解锁、未清数据、未刷机 | 设备状态仍为 `flash.locked=1`、AVB green、未 Root |
| 当前路线 | **A+（Termux/proot + 无 Root 优化）** | 既有服务完全保留 |

> 本机仍是"锁定 + 未 Root"，但 **A 方案运行良好**：proot Ubuntu 24.04.3 LTS 内用 supervisord 管理 9 个服务。

## 3. 已执行的优化（2026-11-10，可完全回滚）

### 3.1 系统设置（8 项，全部生效并复查）

| 设置 | 原值 → 新值 | 目的 |
|---|---|---|
| `global window_animation_scale` | 1 → **0** | 减少渲染开销 |
| `global transition_animation_scale` | 1 → **0** | 同上 |
| `global animator_duration_scale` | 1 → **0** | 同上 |
| `system screen_off_timeout` | 60000 → **15000 ms** | 熄屏更快，省电降温 |

### 6.2 优化回滚（全部可逆）

```powershell
# 一键恢复设置 + 重新启用本次禁用的所有应用
powershell -ExecutionPolicy Bypass -File scripts\apply-a-plus.ps1 -Restore
```

手动回滚（只回滚个别项）：

```powershell
# 恢复某个被禁用应用
scripts\adb.ps1 shell pm enable com.miui.compass
# 恢复某条设置（原值见 inventory\apply-a-plus-latest.md）
scripts\adb.ps1 shell settings put system screen_off_timeout 60000
scripts\adb.ps1 shell settings put system peak_refresh_rate 120
```

### 6.3 服务器数据恢复（若 proot 环境损坏）

```bash

tar xzf a-route-20261110-1100.tgz -C /
# 再按 /root/server/README.md 的"备份与恢复"章节启动 supervisord
```
