# changelog/ 变更归档

> 本目录保存从 [CHANGELOG.md](../CHANGELOG.md) 超窗移出的历史变更摘要。**默认不读**：只在追溯某个变更的来龙去脉时，按月份打开**单个**文件；不得把归档内容当当前状态，也不得复制到其他文档。
> 归档规则与上下文预算的唯一规范见 [MTH-015](../methodology/15-archive-and-context-budget.md)；当前窗口（≤8 条）见 [CHANGELOG.md](../CHANGELOG.md)。

## 1. 归档文件约定

| 项 | 规则 |
|---|---|
| 命名 | `YYYY-MM.md`（按**记录日期**的月份；同名文件持续追加） |
| 顺序 | 时间倒序（最新在上） |
| 内容 | 只保留摘要条目（变更/验证/未完成）；禁止原始日志、命令输出、临时账号、完整测试明细 |
| 性质 | **只读**：归档后不再修改、不拆分、不重排；新条目只追加 |
| 体积 | 单文件 ≤256KB（由 `toolkit validate` 机检）；接近上限时按更细月份拆分并同步索引 |
| 索引 | 由 [CHANGELOG.md](../CHANGELOG.md) §4 维护；本文件 §2 是同一索引的人类可读镜像 |

## 3. 归档操作（每次超窗执行）

1. 当前窗口新增第 9 条时，取**最旧**条目（版本号最小/日期最早）；
2. 从 `CHANGELOG.md` §3 移到对应 `changelog/YYYY-MM.md` 的**顶部**（按日期倒序）；
3. 更新 `CHANGELOG.md` §4 索引与 `changelog/README.md` §2 镜像（条目数、版本范围、链接）；
4. 运行质量门：`python -m toolkit.repurpose validate --strict`、`python scripts/dev/check-links.py --strict-anchors`；
5. 不修改归档文件中的历史结论；只允许修正明显的事实错误并注明。

## 4. Agent 读取边界（重要）

- **默认不读本目录**；只有用户/任务明确要求"追溯历史变更"时才读，且一次只读一个月份文件、只读相关段落（用 grep/offset，禁止整读大文件）。
- 不把归档里的旧数字/旧结论当作当前事实：当前状态看 [docs/00-overview/当前状态.md](../docs/00-overview/当前状态.md)（仅 haydn 案例）、当前方法论看 `methodology/`，当前未完成看 [backlog.json](../backlog.json)。
- 不在归档目录新增非变更类内容；其他文档不得复制归档正文。
- 归档路径受保护：`changelog/` 默认只读，除非执行 §3 的归档操作。
