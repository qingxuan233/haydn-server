# （模板示例）Runbook

> 模板使用说明：`toolkit/templates/runbook.md`。Runbook 是"照着做不会出事"的操作单：
> 每一步都有验证、失败分支与回滚；所有命令只读或受控，禁止把 token/口令写进正文。

## 2. 开始前检查清单

```text
[ ] 备份/快照已完成并可验证
[ ] 回滚路径已确认（命令/文件/镜像均可获得）
[ ] 第二恢复通道可用（SSH/ADB/物理接触）
[ ] 变更窗口与通知已确认
[ ] 无凭据出现在日志/命令行历史
```
