# （模板示例）Runbook

> 模板使用说明：`toolkit/templates/runbook.md`。Runbook 是"照着做不会出事"的操作单：
> 每一步都有验证、失败分支与回滚；所有命令只读或受控，禁止把 token/口令写进正文。

```text

```

## 6. 发布 Go/No-Go 卡（发布类变更必填）

```text
- DRI / 发布 Owner / 时间窗口 / 目标环境：
- 版本、源提交、制品校验值（sha256）：
- 需求基线与已知不做项：
- 构建/测试/安全/许可证/迁移结果：
- 部署与 smoke test 结果：
- 监控、告警阈值、观察窗口、响应人：
- 回滚触发条件、步骤、恢复验证（是否演练过）：
- 未解决风险及批准豁免（批准人/到期日）：
- 决策：GO / NO-GO / 有条件 GO（签核人 + 日期）
```

> 没有记录的"口头通过"视为未通过；Agent 不得自行豁免。

## 7. 事件响应（检测 → 止损 → 回滚 → 升级 → 复盘）

| 阶段 | 动作 | 证据 |
|---|---|---|
| 检测 | 按 §4.1 信号确认影响范围与开始时间 | 告警/日志时间线 |
| 止损 | 先保护人/数据/服务，控制影响面，停止扩大 | 执行命令与时间 |
| 回滚/恢复 | 按 §5 回滚；恢复后复核数据完整性与用户影响 | 回滚结果与校验输出 |
| 升级 | 按联系人表通知主责/替补/用户；重大事件升级 DRI | 通知时间与对象 |
| 复盘 | 记录时间线、影响面、动作、不确定项与改进项（进 PIT/backlog） | 复盘文档相对路径 |

> 禁止为了"修得快"销毁证据或隐瞒回滚；事故记录不得删改。
